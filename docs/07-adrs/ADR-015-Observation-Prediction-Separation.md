# ADR-015

## Title

Observation and Prediction Separation

---

## Status

Accepted

---

## Context

An Observation represents factual execution data generated by an AI Agent.

A Prediction represents an interpretation of that data produced by the ML Engine.

Mixing both concepts into a single object would blur the boundary between raw evidence and analytical results.

---

## Decision

Observations and Predictions are modeled as separate domain entities.

Observations remain immutable records of execution.

Predictions may evolve over time as ML models improve, while the original Observation remains unchanged.

---

## Consequences

### Positive

- Clear domain boundaries.
- Supports future re-analysis using newer ML models.
- Better auditability.
- Cleaner data model.

### Negative

- Additional relationship between entities.
- Slightly more complex persistence model.
