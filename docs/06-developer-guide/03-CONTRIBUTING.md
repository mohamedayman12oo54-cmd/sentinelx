# Contributing

## Purpose

This document defines the engineering practices followed by the SentinelX project.

It helps contributors maintain consistency across the codebase.

---

# General Principles

Contributors should:

- Keep changes small.
- Write clear commit messages.
- Follow project conventions.
- Avoid unnecessary complexity.
- Preserve backward compatibility whenever possible.

---

# Documentation

Any architectural or behavioral change must be reflected in the documentation before implementation is considered complete.

---

# Pull Requests

Every Pull Request should include:

- Clear description.
- Testing summary.
- Documentation updates (if applicable).

---

# Coding Philosophy

SentinelX prioritizes:

- Readability
- Simplicity
- Maintainability
- Explicit design
